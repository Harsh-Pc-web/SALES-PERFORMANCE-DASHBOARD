# 🛒 SALES PERFORMANCE DASHBOARD - - Power BI Project

### Overview
An interactive Power BI dashboard to analyze 12.9 Cr+ sales data, product performance, customer trends and profitability.

### 📊 Key Insights
- **Total Sales: 12.9 Cr+ | Net Sales | Total Profit | Total Discount**
- **Top 5 / Bottom 5 Customers & Products by Sales**
- **Sales Trend Analysis by Month / Year (Seasonal Trends)**
- **Region-wise Performance with Map Visuals**
- **Profitability Analysis by Product Category**

### 🛠️ Tools & Features Used
- **Power BI | Power Query | DAX | Excel**
- KPI Cards, Bar Chart (Top 5 / Bottom 5), Trend Line Chart, Map Visuals
- DAX Measures: Total Sales, Net Sales, Profit, Discount
- Slicers/Filters: Date, Customer, Product and Promotion
